## 🖥️ System Capabilities

This project completely simulates a professional penetration testing environment using **Zero External Dependencies** (No React, No Backend).

### 🚀 **Interactive Terminal**
A fully functional command-line interface running in the browser.
- **`nmap`**: Realistic network scanner. Supports flags:
  - `-h` (Full Help Menu)
  - `-v` / `-vv` (Real-time Verbosity)
  - `-oN` (Output Simulation)
  - `192.168.x.x` ranges
- **`scan`**: Graphical wrapper for running assessment modules.
- **`analyze`**: Deep packet inspection simulation.
- **`whoami`**: Real-time IP and agent detection.

### 🔐 **Virtual Authentication**
- **Login System**: Secure access control for sensitive modules.
- **Role-Based Access**: Restricts unauthorized users from the Database.
- **Session Persistence**: Remembers your "Agent" status.

### 📊 **Vulnerability Database**
- **Dynamic Reporting**: Generates downloadable audit logs (`.txt`).
- **Real-time Logging**: Tracks every command and interaction in the "Access Logs" panel.
