# Social Engineering Awareness Module

## Overview
This module focuses on social engineering assessment, awareness training, and simulation of various social engineering attack vectors.

## Attack Vectors

### 1. Phishing
- Email phishing campaigns
- Spear phishing
- Whaling (CEO fraud)
- Clone phishing
- Vishing (voice phishing)

### 2. Pretexting
- False identity scenarios
- Authority impersonation
- Technical support scams
- Vendor impersonation

### 3. Baiting
- USB drop attacks
- Malicious downloads
- Physical media distribution

### 4. Tailgating
- Physical access attempts
- Unauthorized entry
- Shoulder surfing

### 5. Quid Pro Quo
- Fake services
- Technical support scams
- Information exchange scams

## Testing Framework

### Phishing Simulation
- Email templates
- Landing page creation
- Click tracking
- User awareness metrics

### Physical Security
- Office security assessment
- Access control evaluation
- Visitor management review

### Awareness Training
- Educational materials
- Training modules
- Best practices guides
- Reporting procedures

## Tools

- **Gophish** - Open-source phishing framework
- **SET (Social Engineering Toolkit)** - Social engineering attacks
- **King Phisher** - Phishing campaign toolkit
- **Email templates** - Phishing email templates

## Scripts

- `phishing_simulator.py` - Phishing campaign simulator
- `awareness_quiz.py` - Security awareness quiz generator
- `email_template_generator.py` - Phishing email template generator
